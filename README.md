# Iluminnus

Monorepo da Iluminnus Technology.

- `site/` — site institucional da Iluminnus (Next.js, sem backend).
- `telas/` — o Telas: sistema de gestão de mídia indoor (Next.js + Prisma + Supabase Postgres), multi-tenant. Ver `telas/DISTRIBUICAO.md`.

Cada pasta é um projeto Vercel independente (root directory `site` e `telas`, respectivamente).
